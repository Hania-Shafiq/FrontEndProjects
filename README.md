## Projects
Here is a list of the projects included in this repository:

1. **[Tic-Tac-Toe Game](https://hania-shafiq.github.io/FrontEndProjects/TicTacToeGame/)**
   - Description: A simple Tic-Tac-Toe game created using HTML, CSS, and JavaScript.
   - Status: Completed
   - **How to Check It**: Click on the link above to view and interact with the Tic-Tac-Toe game. It will open in your web browser where you can play the game.

2. **[Calculator](https://hania-shafiq.github.io/FrontEndProjects/Calculator/)**
   - Description: A functional calculator created with HTML, CSS, and JavaScript. It supports basic arithmetic operations such as addition, subtraction, multiplication, and division.
   - Status: Completed
   - **How to Check It**: Click on the link above to view and use the calculator directly in your web browser.

3. **[CSS Slider](https://hania-shafiq.github.io/FrontEndProjects/CssSlider/)**
   - Description: A responsive CSS image slider created using HTML and CSS, showcasing smooth transitions and modern design.
   - Status: Completed
   - **How to Check It**: Click on the link above to view the slider in action. The slider will automatically transition between images, or you can navigate using buttons.

4. **[Article Popup](https://hania-shafiq.github.io/FrontEndProjects/ArticlePopUp/)**
   - Description: A styled article popup built using HTML, CSS, and JavaScript. The popup opens when triggered, and it is designed with animations for better user experience.
   - Status: Completed
   - **How to Check It**: Click on the link above to see the article popup. You can trigger the popup by clicking the button on the webpage.

## How to Run the Projects
To view and interact with any of the projects in this repository, simply click on the project link provided. This will open the project in your web browser.
